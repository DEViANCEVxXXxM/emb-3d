# Embassy of Burgers — «4 за 44 000»

Русскоязычный интерактивный промосайт. Используется исходная 3D-модель бургера **Канада** (GLB) и предоставленные изображения фирменных продуктов Embassy of Burgers.

## Содержимое

- **Акция**: «4 ЗА 44 000 СУМ».
- **Бургер Канада**: исходная текстурированная 3D-модель с поворотом мышью или пальцем.
- **Состав набора**: бургер Канада, Coca-Cola, наггетсы, кетчуп.
- **3D-просмотр**: 4 ракурса, вращение, приближение, отдаление и сброс.
- **Фирменный стиль**: логотип Embassy of Burgers, палитра по брендбуку EMB (январь 2026), El Messiri / Inter.
- **Адаптивность**: десктоп, планшет и мобильные устройства.
- **Режим превью**: если WebGL 2 не поддерживается, вместо 3D показывается изображение *этой же исходной модели*. Промосайт остаётся доступным.

## Как запустить

**Windows:** распакуйте ZIP и запустите `START-WINDOWS.bat`. Требуется установленный Python. В браузере откроется `http://localhost:8080/`.

**macOS / Linux:** в терминале откройте папку проекта и выполните `sh start-mac-linux.sh`. Откройте `http://localhost:8080/`.

Либо выполните в папке проекта:

```bash
python -m http.server 8080
```

Сайт не запускается полноценно простым открытием `index.html` по схеме `file://`: WebGL-просмотр загружает файл GLB через HTTP. Для локального предпросмотра и публикации необходим веб-сервер.

## Структура

```text
index.html                  — русская разметка и контент
styles.css                  — адаптивный фирменный дизайн
app.js                      — навигация и собственный WebGL 2 просмотрщик
assets/burger.glb           — исходная 3D-модель, без замены и переделки
assets/products/            — оптимизированные изображения продуктов и запасной кадр 3D-модели
assets/brand/               — фирменные SVG логотипы и графика
START-WINDOWS.bat           — запуск на Windows
start-mac-linux.sh          — запуск на macOS / Linux
```

## Изменение контента

- Цена, описание и названия — в `index.html`.
- Цвета — CSS-переменные в начале `styles.css`.
- Камеры, скорость автовращения — `SCENES` и `PRESETS` в `app.js`.
- Сменить модель можно через `assets/burger.glb`, но текущий собственный просмотрщик ориентирован на структуру предоставленной модели GLB. Для произвольной модели потребуется настройка кода или стандартный Three.js загрузчик.
- Шрифты **El Messiri** и **Inter** подключаются через Google Fonts. Если сеть недоступна, используются системные запасные шрифты.
